## 📖 项目简介 (Overview)

**AirportMatrix (airportmatrix.cc)** 是一个专注于跨境网络加速方案、IEPL/IPLC 企业级专线测评、全平台客户端图文教程及 AI 大模型访问指南的**现代自然科技风内容矩阵知识库**。

项目以 **“客观实测、拒绝虚标、杜绝跑路”** 为准则，融合了温馨治愈的**森林生态美学**与硬核的**专线网络技术**，建立起覆盖 **46 篇深度结构化文献、2,286 处内部链接、全自动化 SEO 索引安全门禁** 的现代化知识库系统。

## ✨ 核心特色与功能 (Key Features)

### 1. 🌲 自然治愈 × 现代网络科技风 UI (Nature Tech Aesthetics)
- **3D 世界树数据中枢**：高精度 3D 浮岛拓扑主图，呈现全球专线节点数据流向与毫秒级延迟；
- **动态生态交互**：柔和飘落的常青叶片、夏夜萤火虫流光粒子、顶部翡翠渐变阅读进度条；
- **全天候智能选机助手**：右下角悬浮 **“森之精灵 · 芽芽”** 交互式弹窗，支持 30 秒场景匹配与故障急救；
- **磨砂玻璃与木纹质感卡片**：全站原生适配暗黑模式（Dark Mode），兼具高可读性与高级视觉层次。

### 2. ⚡ 2026 稳定机场推荐天梯榜 (IEPL/IPLC 真实压测)
- **TOP 4 综合实力旗舰速览**：涵盖 **光速云** (5年老牌 No.1)、**飞猫云** (约7元性价比)、**微风网络** (轻量低丢包)、**星岛梦** (老牌不限时按量)；
- **多维度横评罗盘**：支持按 **综合排序、价格排序、推荐等级** 筛选 17 家服务商，内嵌真实测速大图弹窗查看器；
- **金色光纤与翡翠水晶实时拓扑**：实时呈现香港（28ms）、东京（62ms）、新加坡（54ms）、美西（138ms）节点指标。

### 3. 🤖 AI 大模型访问与流媒体全解 (GEO 深度优化)
- **ChatGPT / Claude 3.5 报错急救**：针对 `Access Denied`、`Not Available in Your Country` 提供 30 秒即时排查方案；
- **原生住宅 IP 与机房 IP 深度剖析**：提供防封号、防验证码与 TikTok 跨境电商专用网络指南；
- **Netflix / Disney+ 4K 影音解锁**：针对非自制剧全区片库的原生解锁测试。

### 4. 📱 全平台客户端零门槛保姆教程 (Zero-Threshold Guides)
- **Windows / Mac / iOS / Android 全覆盖**：涵盖 **Clash Verge Rev、Shadowrocket (小火箭)、v2rayN、sing-box** 图文 step-by-step 安装与一键订阅导入；
- **30秒智能故障排查向导**：交互式选择“节点全红”、“订阅打不开”、“连上没网”等常见症状，即时输出排查步骤。

### 5. 🛡️ 工业级 SEO 防掉索引与发布安全门禁 (SEO Health Gate)
- **自动化安全检查 (`npm run seo:check`)**：发布前自动扫描 `robots.txt`、`canonical`、`noindex`、`sitemap.xml`、2,286 处站内死链与黑产目录；
- **动态 Schema 注入**：构建期自动解析正文 FAQ 问答生成 `FAQPage` JSON-LD，内置 `WebSite` 与 `SearchAction`；
- **即时索引支持**：原生内置 **IndexNow** 协议验证，内容发布即刻主动推送至 Bing、Yandex 爬虫。

## 🛠️ 技术栈 (Tech Stack)

| 领域 | 选型与工具 | 说明 |
| :--- | :--- | :--- |
| **SSG 引擎** | [VitePress v1.6.4](https://vitepress.dev/) | 基于 Vite + Vue 3 的极速静态站点生成器 |
| **前端交互** | Vue 3 (Composition API) + TypeScript | 模块化交互组件（横评罗盘、向导、节点拓扑） |
| **样式系统** | Tailwind CSS + CSS 变量定制 | 自然森林绿与科技蓝双主题配色体系 |
| **全文检索** | [Pagefind Extended](https://pagefind.app/) | 离线静态全文索引（4,000+ 词库，中文分词支持） |
| **自动化测试** | [Playwright Test](https://playwright.dev/) | 12 项 E2E 页面渲染与功能回归测试 |
| **SEO 门禁** | Node.js 自研 Health Check 脚本 | 8 重防掉索引与规范化发布安全拦截 |

## 🚀 快速开始 (Quick Start)

### 1. 克隆项目与安装依赖

```bash
git clone https://github.com/qweqwe98698-tech/airportmatrix.cc.git
cd airportmatrix.cc

# 安装项目依赖
npm install
```

### 2. 本地开发调试

```bash
# 启动本地热重载开发服务器 (默认端口 http://localhost:5173)
npm run dev
```

### 3. 构建生产版本与 SEO 检查

```bash
# 构建静态 HTML 产物并生成 Pagefind 索引
npm run build

# 运行自动化 SEO 安全门禁检查 (防掉索引)
npm run seo:check

# 启动本地生产预览服务器
npm run preview
```

### 4. 运行端到端测试 (Playwright)

```bash
# 运行 12 项 E2E 自动化测试
npm run test:e2e
```

## 🛡️ SEO 安全发布流程 (CI/CD Quality Gate)

本项目已建立标准发布工作流，任何上线部署前必须确保所有安全检查为 `PASS`：

```text
内容编写 / 评测更新
       ↓
本地编译 (npm run build)
       ↓
SEO 门禁扫描 (npm run seo:check)
  ├── 1. robots.txt 检查 (无全站 Disallow)
  ├── 2. sitemap.xml 检查 (45 规范 URL，无 localhost)
  ├── 3. Canonical 检查 (100% 自引用一致)
  ├── 4. Noindex 检查 (0 异常 noindex)
  ├── 5. 内部死链扫描 (2286 处链接 0 死链)
  ├── 6. 异常黑产目录扫描 (无未知路径)
  └── 7. IndexNow 验证密钥就绪
       ↓
E2E 自动化测试 (npm run test:e2e)
       ↓
全绿通过 (RELEASE_DECISION: READY) ➔ 部署推送至 GitHub / 生产环境
```
