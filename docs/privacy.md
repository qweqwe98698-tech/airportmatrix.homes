# 🔒 隐私政策与数据安全声明

**生效日期：2026年1月1日**  
**最近修订：2026年10月**

**全球机场 · 森林知识屋 (AirportMatrix)**（以下简称“本站”或“我们”）深知隐私对读者的重要性。我们致力于践行“数据最小化（Data Minimization）”与“设计即隐私（Privacy by Design）”原则。本政策详细阐明我们在您浏览本站知识库及使用评测数据时如何处理相关信息。

---

## 🚫 1. 零个人身份信息收集原则 (Zero-PII Policy)

* **无用户账户系统**：本站为公开、免费的技术评测知识库，不提供亦不强制要求用户注册账号，我们不收集亦不存储您的真实姓名、手机号码、身份证件、家庭住址或社交媒体账号；
* **无支付交易系统**：本站不直接销售任何网络工具或增值服务，不收集或记录任何银行卡号、信用卡安全码（CVV）或第三方支付凭据；
* **无私有用户数据库**：本站采用 VitePress 纯静态网站生成技术（Static Site Generation），后端不连接任何写入型关系数据库，杜绝用户敏感数据泄露隐患。

---

## 🌐 2. 服务器访问日志与 CDN 安全网络

当您访问本站时，我们的托管基础设施与全球分发网络（如 Cloudflare 等 CDN 服务商）会自动记录标准的 Web 访问日志：

* **日志收集内容**：请求发起时间戳、访问的 URL 路径、HTTP 状态码、请求大小、浏览器 User-Agent 字符串以及匿名的粗粒度网络来源。
* **数据用途**：仅用于拦截恶意 DDoS 洪水攻击、自动化爬虫频率限制、排查破损链接（404）以及评估全站缓存命中率。
* **保留期限**：此类匿名系统日志仅在边缘节点临时留存，并在安全审计周期后自动滚动清理或销毁。

---

## 🍪 3. 本地存储 (LocalStorage) 与 Cookie 使用

本站追求极简与纯净，**不使用任何用于跨网站广告追踪（Cross-Site Tracking）的第三方追踪 Cookie**。

我们仅使用现代浏览器原生的 `LocalStorage` 与必要会话存储来实现以下基础功能：
* **界面主题偏好**：记录您所选取的明亮（Light）或暗黑（Dark）森林主题模式；
* **Pagefind 静态检索**：用于在您的本地浏览器端极速检索文章索引片段，所有检索运算均在您的客户端本地完成，绝不会将您的检索词上传至任何远程服务器。

---

## 🔗 4. 第三方服务与外部链接免责

本站包含大量指向外部第三方平台（包括各网络服务品牌官网、开源客户端 GitHub 仓库、学术工具官方页面等）的超链接：

* 一旦您点击链接离开本站并跳转至第三方网站，本隐私政策将不再适用；
* 第三方网站拥有其独立的隐私权条款与数据收集政策，我们无法控制亦不对第三方的隐私行为承担法律责任；
* 我们强烈建议您在向任何第三方网站提供个人信息或进行金融支付前，仔细审阅其官方公布的隐私政策与服务协议。

---

## 🧒 5. 未成年人隐私保护

本站内容面向具备完全民事行为能力的网络技术爱好者、科研人员及跨境网络从业者。我们不会有意收集或诱导未满 18 周岁未成年人的任何个人数据。
