## 🔬 一、什么是 IPLC？(International Private Leased Circuit)

### 1. 概念与定义
**IPLC（国际私有租用线路）** 是最传统的跨境点对点通信解决方案。它由电信运营商在两个国家/地区之间铺设物理光缆或租用固定海底光纤通道，直接将客户端机房与海外端机房相连。

### 2. 核心架构特点
* **物理级点对点**：相当于一条跨越国界的专属私有光缆，中间不经过任何公网交换机；
* **完全物理不过墙**：数据包从深圳机房进入光缆，直接在香港机房出来，**完全不经过 GFW 的公网出口监控节点**；
* **极速与零抖动**：物理时延恒定（深圳到香港约为 2~5ms，上海到东京约为 25ms），抖动接近 0。

---

## ⚡ 二、什么是 IEPL？(International Ethernet Private Line)

### 1. 概念与定义
**IEPL（国际以太网专线）** 是在 IPLC 基础上发展而来的新一代以太网级专线服务。它基于运营商的传输网（如 SDH/OTN 或 MPLS 骨干网），为企业提供二层（Layer 2）以太网虚拟内网连接。

### 2. 核心架构特点
* **以太网二层透明传输**：支持标准的以太网数据帧封装，具备弹性带宽扩容能力；
* **内网安全过境**：同样属于运营商内部数据中心互联专网，过境流量不走公网，因此同样**完全不受 GFW 干扰**；
* **成本适中、性价比高**：相比死板昂贵的纯物理 IPLC，IEPL 支持运营商动态调度与冗余热备，单位带宽成本有所降低。

## 📊 三、IEPL 与 IPLC 全维度对比表

| 对比维度 | IPLC (国际私有租用线路) | IEPL (国际以太网专线) | 普通公网 BGP 中转 |
| :--- | :--- | :--- | :--- |
| **网络层级** | 物理层 / 一层 (Layer 1) | 数据链路层 / 二层 (Layer 2) | 网络层 / 三层 (Layer 3) |
| **过境方式** | 专属物理海底光纤 | 运营商 OTN/MPLS 内网以太网 | 经由公网加密隧道穿透 GFW |
| **GFW 审查** | **100% 物理跳过** | **100% 物理跳过** | 容易被识别阻断入口 IP |
| **敏感期稳定性** | 极高（永不掉线） | 极高（稳如磐石） | 偶有入口维护切换 |
| **单 Gbps 带宽月费** | ¥35,000 ~ ¥50,000+ | ¥20,000 ~ ¥30,000 | ¥3,000 ~ ¥8,000 |
| **网络抖动** | &lt; 0.5ms | &lt; 1.5ms | 5ms ~ 20ms |

## ❓ 专线技术常见问答 (FAQ)

::: details 1. 为什么几块钱的低价直连机场晚高峰会断流，而 IEPL 专线不会？
公网直连必须经过国际公网出口与拥堵路由节点，晚高峰 20:00–23:00 丢包率可飙升至 15%–40%；IEPL 走运营商内部二层物理专线传输，彻底绕开公网拥堵出口，因此晚高峰延迟与丢包曲线几乎保持水平。
:::

::: details 2. 普通用户怎么验证一个机场是不是真的 IEPL 专线？
可同时观察三项表现：① 晚高峰 21:00 左右香港/新加坡节点 ping 抖动是否低于 2ms；② 敏感周期内入口是否大面积超时；③ 是否与市场正常专线成本相符。详见 [AirportMatrix 评测方法论](/methodology)。
:::
