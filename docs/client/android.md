## 📱 二、v2rayNG 保姆级图文配置步骤 (以新手为例)

### 1. 客户端下载与安装
* **官方推荐下载渠道**：从 GitHub 官方发布页（`2dust/v2rayNG`）下载最新的 `v2rayNG_x.x.x_arm64-v8a.apk` 安装包；
* **权限授予**：安装后首次打开，同意创建本地 VPN 连接（系统会提示“v2rayNG 正在请求创建 VPN 连接”，点击【确定】）。

### 2. 导入机场订阅链接
1. 登录你的机场用户后台（如 [光速云 (👑全网主推第一)](/ranking/guangsu) 或 [飞猫云](/ranking/)）；
2. 找到【一键订阅】-> 点击【复制通用订阅链接】或【复制 v2ray 订阅】；
3. 打开 v2rayNG，点击左上角【三条横线菜单】-> 选择 **【订阅设置】**；
4. 点击右上角 **【+】号**，在“备注”中输入机场名称（如 `光速云专线`），在“地址 (url)”中粘贴刚才复制的订阅链接，点击右上角保存；
5. 返回主界面，点击右上角 **【三个点】菜单** -> 选择 **【更新订阅】**，节点列表瞬间加载完毕！

### 3. 设置智能分流（绕过大陆）
* 打开左侧菜单 -> 进入 **【设置】** -> 找到 **【预定义规则】**；
* 将路由模式修改为 **【绕过局域网及大陆地址 (bypass LAN and mainland China)】**；
* 这样设置后，访问国内淘宝、微信、抖音走国内高速直连，访问 Google、YouTube、ChatGPT 自动走代理加速。

## 🔋 三、手把手解决华为 / 小米 / OPPO / vivo 后台频繁被杀

国内手机定制安卓系统（MIUI/HyperOS、HarmonyOS、ColorOS、OriginOS）拥有极为激进的后台清理机制。按以下 3 步设置即可彻底解决“锁屏后断网”：

```
[第 1 步: 应用锁定] ➔ 打开手机多任务后台 ➔ 长按代理客户端卡片 ➔ 点击【加锁图标】
        │
[第 2 步: 电池优化] ➔ 系统【设置】->【应用管理】-> 找到客户端 ->【耗电管理】-> 选【允许无限制后台运行】
        │
[第 3 步: 自启动权限] ➔ 系统【权限管理】-> 开启【允许自启动】与【允许被其他应用关联唤醒】
```

## ❓ Android 科学上网常见 10 大疑问与解答 (FAQ)

::: details 1. 为什么华为 HarmonyOS 安装 v2rayNG 提示风险软件？
国内厂商会对所有包含代理/VPN 代码的应用弹出“纯净模式风险提醒”。请在安装界面点击“了解风险并继续安装”即可，官方开源版本 100% 无毒安全。
:::

::: details 2. 安卓手机开启代理后很耗电怎么办？
1. 在客户端设置中关闭“Mux 多路复用”；
2. 在路由分流中开启“绕过局域网及大陆”，避免代理接管所有国内后台应用的轮询唤醒；
3. 首选轻量化的 `v2rayNG` 或 `sing-box` 代替体积较大的图形客户端。
:::

::: details 3. 为什么连接成功后，屏幕上方没有显示“钥匙 🔑 / VPN”图标？
部分 Android 13/14 系统（如 OriginOS）将 VPN 图标折叠进了下拉控制中心。只要在客户端界面点击【测速】能返回正常延迟数字，即代表 VPN 通道已正常建立。
:::

::: details 4. 怎么把安卓手机的代理网络共享给电脑或 Switch 游戏机？
在 v2rayNG 设置中开启 **【允许来自局域网的连接】**，查看手机当前 Wi-Fi IP（如 `192.168.1.100`）及 Socks/HTTP 端口（默认 `10808` / `10809`），在电脑或 Switch 的网络设置中配置该代理即可。
:::

::: details 5. 为什么手机在 Wi-Fi 下能用，切换到 4G/5G 流量后就断网了？
这是本地运营商的移动网络 APN 配置限制或开启了手机“智能网络切换”。在手机设置中重置 APN 为默认，或在客户端中重新点击断开后再次连接。
:::

::: details 6. 安卓手机怎么使用 Google Play 商店下载应用？
手机必须具备 Google 移动服务（GMS 框架）。在开启代理后，登录你的 Google 账号，即可畅享 Play 商店内数百万正版应用。
:::

::: details 7. 小米手机开启代理后微信收不到消息怎么办？
在分流规则中确认已将 `weixin.qq.com` 与微信相关域名设为 `DIRECT (直连)`，并在应用管理中给予微信完整的常驻后台白名单。
:::

::: details 8. 为什么订阅更新时提示 “Handshake Error” 或握手失败？
通常是因为手机系统时间与北京时间存在误差（超过 60 秒会导致 TLS 握手鉴权失败）。进入系统【日期与时间】设置，开启【自动从网络同步时间】。
:::

::: details 9. 安卓客户端推荐使用哪个节点协议最稳定？
推荐使用 **VLESS Reality** 或 **Shadowsocks (AEAD)** 协议，具有极高的加密抗封锁强度和超低的 CPU 计算开销。
:::

::: details 10. 换了新手机怎么一键迁移所有节点配置？
在旧手机客户端中点击右上角【导出配置文件到剪贴板】或生成订阅二维码，新手机直接扫码即可一秒完成迁移。
:::
