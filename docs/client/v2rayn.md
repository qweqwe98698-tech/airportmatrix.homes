**v2rayN** 是 Windows 平台历史最悠久、稳定性最高、资源消耗最低的开源代理工具。它支持 **Xray-core** 与 **sing-box-core** 双顶级内核，能够原生支持 VLESS（含 Reality）、Trojan、Shadowsocks、Hysteria2、TUIC 等全协议生态。

本篇指南将从 **环境安装、订阅导入、路由分流、TUN 模式游戏加速** 到 **关闭代理后浏览器断网急救** 进行全流程保姆级拆解。

### 1. 学习目标
* 正确下载并配置运行环境（解决打开闪退或弹窗报错问题）；

* 区分并灵活运用「系统代理」与「TUN 虚拟网卡模式」；
* 解决关闭客户端后浏览器打不开网页的经典系统代理残留故障。

### 2. 准备工作

* 运行环境：Microsoft .NET 8.0 Desktop Runtime（官方免费组件）；
* 节点订阅：有效的机场订阅链接（如 [光速云 5年老牌专线](/ranking/guangsu)）。

## 📥 第一阶段：下载与安装（避坑防闪退）

### 1. 下载推荐版本
* 访问 GitHub 官方仓库 `2dust/v2rayN` 的 Releases 页面；
* 推荐直接下载集成全内核的完整安装包：**`v2rayN-With-Core.zip`**（已内置 Xray、sing-box 内核，无需手动配置核心路径）。

### 2. 规范解压路径（极重要）
> ⚠️ **新手陷阱**：严禁在压缩包内直接双击运行！严禁将解压文件夹放在包含中文或特殊符号的路径下（例如 `C:\Users\张三\Desktop\`）。

1. 将 `v2rayN-With-Core.zip` 解压至纯英文路径，例如：`D:\Program Files\v2rayN\`；
2. 双击打开文件夹中的 **`v2rayN.exe`**；
3. 如果系统弹出提示缺少运行库，请下载并安装微软官方 **.NET 8.0 Desktop Runtime (x64)** 即可正常打开。

## 🔗 第二阶段：添加并更新机场订阅

```
┌─────────────────────────────────────────────────────────────┐
│ 步骤 1: 顶部菜单栏点击【订阅分组】 -> 【订阅分组设置】        │
│ 步骤 2: 点击左下角【添加】                                  │
│ 步骤 3: 【别名】输入机场名 (如 "光速云")                     │
│ 步骤 4: 【可选地址(Url)】粘贴订阅链接                         │
│ 步骤 5: 点击【确定】保存                                    │
│ 步骤 6: 顶部菜单栏点击【订阅分组】 -> 【更新当前订阅(不通过代理)】 │
└─────────────────────────────────────────────────────────────┘
```

1. 更新完成后，主界面将列出所有节点（包含香港 IEPL 专线、日本、美国等）；
2. 按快捷键 **`Ctrl + A`** 全选所有节点，右键点击选择 **【测试服务器 Real Delay (真实延迟 / 真连接)】**；
3. 稍等 3 秒，列表【测试结果】一栏将显示真实的毫秒延迟（如 `35ms` 为通畅，`超时 / -1` 为不可用）。

## 🚀 第三阶段：选择活动节点与开启系统代理

1. 鼠标单击选中延迟最低的专线节点，按下键盘 **`Enter (回车键)`**，该节点文字会变为**蓝色加粗**，代表已被设为当前活动节点；
2. 查看 Windows 屏幕右下角任务栏的 **v2rayN 小图标 (V 字图标)**；
3. 鼠标右键点击图标：
   * **【系统代理】** ➔ 勾选 **【自动配置系统代理】**（此时托盘图标会由蓝色变为**红色或粉色**，代表已接管浏览器流量）；
   * **【路由】** ➔ 勾选 **【绕过大陆 (Whitelist) / 规则分流】**（确保微信、QQ、Bilibili 直连，不浪费海外专线流量）。

## 🎮 第四阶段：进阶技能 —— 开启 TUN 虚拟网卡模式

普通「系统代理」只能代理浏览器流量，而无法代理命令行（CMD/PowerShell）、Git、游戏客户端或部分桌面软件。通过开启 **TUN 模式**，v2rayN 可以在 Windows 底层创建虚拟网卡接管整机所有网络流量。

```
                    ┌─────────────────────────┐
                    │     整机所有网络数据    │
                    └────────────┬────────────┘
                                 │
                   [TUN 虚拟网卡虚拟适配器]
                                 │
            ┌────────────────────┴────────────────────┐
            ▼                                         ▼
   [国内 IP / 域名]                         [国外 IP / 域名]
            │                                         │
    (本地直连发送)                     (通过 VLESS / IEPL 专线代理)
```

### 开启步骤：
1. 确保以**管理员身份**运行 v2rayN；
2. 在 v2rayN 主界面底部，找到 **【启用 TUN 模式】** 复选框并勾选；
3. 首次开启时 Windows 会弹出防火墙或网卡驱动安装提示，点击【允许】；
4. 此时电脑上的所有应用程序（包括 Steam 游戏、Discord 语音、Git 命令行）都将无缝走专线加速。

## ❓ v2rayN 常见 10 大故障排查与解答 (FAQ)

::: details 1. 软件关闭后，电脑打不开任何网页，微信却能正常聊天？
**根因**：关闭软件时未将「系统代理」重置，导致 Windows 网络设置中残留了一个无效的本地代理端口（如 `127.0.0.1:10809`）。  
**急救方法**：
1. 打开 Windows【设置】->【网络和 Internet】->【代理】；
2. 将【使用代理服务器】开关手动切换为 **【关】**，网页即可瞬间恢复正常；
3. 良好习惯：每次退出 v2rayN 前，右键托盘图标将系统代理切为【清除系统代理】后再退出。
:::

::: details 2. 为什么更新订阅时提示“基础连接已经关闭”或更新失败？
**排查步骤**：
1. 检查电脑系统时间是否与北京时间一致（误差 > 60 秒会导致 TLS 证书验证失败）；
2. 在订阅分组设置中勾选【跳过证书验证 (不安全)】尝试重新拉取；
3. 将订阅 URL 复制到浏览器直接打开，若能下载文件说明链接正常，可能是当前网络 DNS 污染，可在软件中更换 DNS。
:::

::: details 3. Xray-core 与 sing-box-core 应该选哪个内核？
* 追求极致稳定与经典 VLESS / Shadowsocks 协议：选择 **Xray-core**；
* 追求极低内存占用、高并发多线程与 Hysteria2 / TUIC 新协议：选择 **sing-box-core**。两者均可在【设置】->【核心设置】中随时切换。
:::

::: details 4. Real Delay（真连接测速）和 Ping 测速有什么区别？
* **Ping 测速**：仅测试你的电脑到代理服务器入口的 TCP/ICMP 延迟，不能证明节点能连通外网；
* **Real Delay (真连接测速)**：实际向 Google 握手发送 HTTP 请求并记录响应时间，只有显示具体数值的节点才是真正能出海的可用节点。
:::

::: details 5. 如何让 CMD 命令行与 Git 走代理？
在 PowerShell 中运行以下两行命令即可为当前终端设置临时代理：
```powershell
$env:HTTP_PROXY="http://127.0.0.1:10809"
$env:HTTPS_PROXY="http://127.0.0.1:10809"
```
或者直接在 v2rayN 底部开启 **【TUN 模式】**，整机命令行将自动走代理，无需额外设置环境变量。
:::

::: details 6. 为什么连接节点后访问国内网站变慢？
请检查右下角托盘图标的【路由】模式，必须保持为 **【绕过大陆 (Whitelist)】**。如果误选为【全局 (Global)】，访问百度、淘宝也会绕道海外节点，从而产生高延迟。
:::

::: details 7. v2rayN 是否支持自建节点导入？
支持。点击顶部【服务器】菜单，可自由添加 VMess、VLESS、Trojan、Shadowsocks、Socks、HTTP 以及自定义 JSON 服务器配置。
:::

::: details 8. 如何设置开机自启并自动最小化到托盘？
点击顶部【设置】->【选项设置】-> 勾选 **【开机自动启动】** 与 **【启动时最小化到托盘】**，点击确定保存。
:::

::: details 9. v2rayN 占用电脑内存高吗？
v2rayN 采用 C# WPF 架构，主进程内存占用通常仅 **30MB ~ 60MB**，后台内核几乎不消耗 CPU 资源，对电脑日常办公与游戏性能无任何影响。
:::

::: details 10. 为什么开启 TUN 模式后电脑无法连接公司局域网内网？
在 TUN 模式设置中，将局域网私有网段（如 `192.168.0.0/16`、`10.0.0.0/8`）加入【白名单 / 直连网段列表】即可保留内网互通。
:::
