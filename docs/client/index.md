## 🛡️ 客户端安全避坑提示
1. **只从官方开源 GitHub Release 或 App Store 下载**：切勿在第三方百度搜索结果下载带有“破解版”、“绿色汉化版”字样的安装包，防止被植入木马后门窃取密码。
2. **iOS 用户切勿在国区 App Store 搜索**：Shadowrocket、Quantumult X 仅在海外区（美区/港区等）App Store 上架，需使用外区 Apple ID 下载。
