## ⚡ 第二阶段：导入机场订阅链接 (两种方式)

### 方式 A：一键导入（最推荐，耗时 5 秒）
1. 使用 iPhone 的 Safari 浏览器登录机场后台（例如登录 [光速云用户中心](https://sahude.gsyvipaff.com/#/?code=keqgvT5Y)）；
2. 找到【一键导入订阅】按钮，在弹出的选项中点击【导入到 Shadowrocket】；
3. 系统会自动唤起小火箭应用，并在弹窗中提示“已成功添加订阅”，点击【保存】即可。

### 方式 B：手动复制链接导入
1. 在机场后台复制【Shadowrocket 订阅链接】或【通用订阅链接】；
2. 打开 Shadowrocket，点击右上角的 **➕ 号**；
3. 在【类型】中选择 **Sub (Subscribe / 订阅)**；
4. 在【URL】一栏长按粘贴刚刚复制的订阅链接；
5. 在【备注】一栏输入机场名称（如 `光速云`），点击右上角【保存】；
6. 软件会自动向服务器拉取最新节点列表。

## 🧭 第三阶段：全局路由模式与日常使用

在 Shadowrocket 首页中央，有四种【全局路由】模式，请根据你的使用需求正确选择：

| 路由模式 | 工作原理 | 推荐使用场景 |
| :--- | :--- | :--- |
| **配置 (Config)** ⭐ 默认推荐 | 根据内置分流规则判断：国内流量直连、国外被阻断网站走代理 | **99% 日常使用场景**。既不影响微信/淘宝/美团速度，又能流畅访问 Google/ChatGPT。 |
| **代理 (Proxy)** | 所有流量无论国内外，全部强制走选中的代理节点 | 遇到特定国外网站打不开、或需要临时将 IP 伪装成海外机房时使用。 |
| **直连 (Direct)** | 所有流量全部不经过代理，直接由本地网络发起连接 | 相当于关闭代理软件，排查本地宽带故障时使用。 |
| **场景 (Scene)** | 根据连接的 Wi-Fi SSID 或蜂窝网络自动切换不同路由规则 | 进阶办公场景，如公司内网自动直连，外部网络走代理。 |

## 🛠️ 第四阶段：一键启动与系统 VPN 权限授权

1. 在节点列表中点击选择一个低延迟节点（如 `香港专线01` 或 `日本01`）；
2. 拨动顶部的 **【未连接 / 已连接】主开关**；
3. 如果是首次使用，iOS 系统会弹出系统弹窗：`“Shadowrocket”想要添加 VPN 配置`；
4. 点击 **【允许】**，并通过 iPhone 的 **面容 ID (Face ID)** 或输入锁屏密码进行授权；
5. 当手机状态栏右上角或控制中心出现 **[VPN]** 小图标时，即代表已成功开启代理！

## 🚀 进阶技巧：订阅自动更新与测速排序

### 1. 开启节点自动更新
为防止机场更换节点服务器导致断连，建议开启自动定时更新：
* 点击底部【设置】 -> 【订阅】；
* 勾选 **【打开时更新】** 与 **【后台自动更新】**。

### 2. 节点连通性测速
* 在首页点击【连通性测试】 -> 选择【测试方法：TCP / ICMP / HTTPS】；
* 稍等 2 秒，每个节点后方会显示具体的毫秒延迟（如 `25ms` 为极佳，`Timeout` 为超时）。

## ❓ Shadowrocket 常见 10 大疑问与排错解答 (FAQ)

::: details 1. 为什么连上小火箭后微信发不出图片、美团无法定位？
**根因**：你的全局路由模式被误选为了【代理】而非【配置】。  
**解决方法**：在小火箭首页将【全局路由】切回 **【配置 (Config)】**，国内 App 流量将自动直连，不再走海外节点。
:::

::: details 2. 为什么所有节点测速都显示“Timeout”全红？
**根因**：通常为系统时间不同步或订阅链接失效。  
**解决步骤**：
1. 打开 iPhone【设置】->【通用】->【日期与时间】，开启【自动设置】确保时间精确；
2. 在小火箭中找到订阅分组，左滑点击【更新】拉取最新节点。
:::

::: details 3. 可以在淘宝或拼多多买共享 Apple ID 下载小火箭吗？
可以购买带有 Shadowrocket 兑换码或已购小火箭的独享 ID，但**切记严禁在 iPhone【设置】顶部的 iCloud 登录别人的账号**（会导致手机被远程锁死为砖头）。必须且仅能在 **【App Store】** 商店内登录下载。
:::

::: details 4. 小火箭耗电量看起来很高，正常吗？
iOS 系统的电池统计机制会将所有经过小火箭代理转发的流量（如刷 YouTube 4K、TikTok 视频产生的耗电）统一计入 Shadowrocket 名下。实际上小火箭本身 CPU 占用率极低（< 2%），无需担心异常耗电。
:::

::: details 5. 如何配置 ChatGPT / OpenAI 专用分流规则？
在【配置】页面长按默认配置文件 `default.conf` -> 点击【编辑配置】 -> 添加规则：`DOMAIN-KEYWORD, openai, PROXY` 和 `DOMAIN-SUFFIX, chatgpt.com, PROXY`，确保流量必定经过支持 AI 解锁的专线节点（如 [光速云](/ranking/guangsu)）。
:::

::: details 6. 开启小火箭后能否开启手机个人热点给电脑用？
可以。在小火箭【设置】中开启【允许来自局域网的连接】，记录下显示的代理端口（默认 `1082`），电脑连接手机热点后在电脑端配置该局域网代理即可共享出海。
:::

::: details 7. 小火箭支持哪些协议？
Shadowrocket 支持业界全主流协议，包括 Shadowsocks、ShadowsocksR、VLESS、VMess、Trojan、Snell、SOCKS5、HTTP 以及最新的 Hysteria2 与 TUIC。
:::

::: details 8. 为什么有的节点看不了 Netflix 原画非自制剧？
Netflix 会对公共机房 IP 进行严格封锁。若要观看全区片库，请在节点列表中选择标注有 `原生 / 解锁 / 流媒体` 的专用专线节点（如 [光速云 70节点全解锁](/ranking/guangsu)）。
:::

::: details 9. 小火箭的 HTTPS 解密证书有什么用？
HTTPS 解密用于抓包分析和去除特定网页广告。对于单纯科学上网、查资料、看视频的普通用户，**完全不需要安装证书**，保持默认关闭即可。
:::

::: details 10. 如何在不同 Wi-Fi 环境下自动开关代理？
点击底部【配置】-> 切换到【场景】模式，可以针对家里的 Wi-Fi、公司 Wi-Fi 和蜂窝移动网络分别指定启用或直连规则，实现完全无感自动化。
:::
