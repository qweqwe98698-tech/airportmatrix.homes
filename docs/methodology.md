# 📊 评测方法论与质检标准

为了彻底摒除主观臆测与商业营销滤镜，**全球机场 (AirportMatrix)** 制定了严谨的标准化网络评测体系。本文档全面公开我们的评测环境、数据采集流程、质量量化模型与加权评分算法。

---

## 🔬 六步标准化测试流程

每个纳入深度评测的服务商必须完整走完以下六阶段闭环评测：

```
[1. 匿名自费订阅] ──> [2. 节点拓扑逆向与 MTR] ──> [3. 晚高峰全负载压测]
                                                               │
[6. 综合评分与归档] <── [5. 客户端稳定性与售后] <── [4. AI/流媒体风控检测]
```

1. **匿名自费订阅**：测试人员使用普通用户账号与常规支付方式购入主流月付/季付套餐，杜绝厂商针对白名单账号的资源倾斜。
2. **节点拓扑与路由逆向**：使用深度路由跟踪（MTR）、BGP 路由表分析及 ICMP 时延比对，核验入口机房、跨境过境跳数与出口机房，鉴别真实专线与公网伪专线。
3. **晚高峰全负载压测**：在 20:00 - 23:30（骨干网拥塞极值窗口），运行自研自动化探针持续采集丢包率、延迟抖动与多线程峰值带宽。
4. **AI 与流媒体风控矩阵检测**：调用自动化检测脚本验证 Netflix 非自制剧、Disney+、YouTube Premium，并调用 OpenAI / Anthropic 接口验证 IP 纯净度与欺诈评分。
5. **客户端兼容与容灾演练**：测试在断网重连、节点主备切换及主流客户端（Clash Verge Rev、Sing-box、Surge、Shadowrocket）下的配置渲染与协议兼容性。
6. **评分模型量化归档**：输入采集数据至量化评分系统，输出雷达图与评测结论，所有原始日志归档存证。

## 📐 五大核心量化指标与判定阈值

| 指标维度 | 采集工具与方法 | 优秀阈值（A 级） | 可用阈值（B 级） | 警戒阈值（C 级） |
| :--- | :--- | :--- | :--- | :--- |
| **晚高峰丢包率** | MTR 连续 500 次 ICMP/TCP 探测 (20:30-22:30) | < 1.0% | 1.0% ~ 5.0% | > 8.0% |
| **延迟抖动 (Jitter)** | 分布式探针连续计算延迟标准差 ($\sigma$) | $\sigma \le 5\text{ms}$ | $5\text{ms} < \sigma \le 20\text{ms}$ | $\sigma > 40\text{ms}$ |
| **单线程吞吐** | YouTube 4K/8K 视频首帧与 Connection Speed | $\ge 80,000\text{ Kbps}$ | $30,000 \sim 80,000\text{ Kbps}$ | $< 15,000\text{ Kbps}$ |
| **IP 欺诈分 (Fraud)** | IPQualityScore / Scamalytics 风险库检索 | $\text{Score} < 15$ | $15 \le \text{Score} < 40$ | $\text{Score} \ge 60$ |
| **节点可用率 (SLA)** | 7×24 小时每 5 分钟健康心跳探活 | $\ge 99.5\%$ | $98.0\% \sim 99.5\%$ | $< 95.0\%$ |

## 🛠️ 底层拓扑鉴别标准

市场中存在大量以“廉价中转”冒充“专线”的现象。实验室采用严格的物理时延常数进行技术甄别：

* **真 IPLC / IEPL 专线**：
  * 上海 - 日本物理延迟约为 $25\text{ms} \sim 32\text{ms}$；
  * 深圳 - 香港物理延迟约为 $4\text{ms} \sim 7\text{ms}$；
  * 全天 24 小时延迟波动稳定在 $\pm 2\text{ms}$ 以内，不经过公网国际出口路由器（如 202.97 或 59.43），晚高峰零丢包。
* **公网中继（Transit Tunnel）**：
  * 国内入口通过公网中转服务器汇聚，再经公网 163 骨干网出海；
  * 晚高峰延迟显著上浮（+30ms 至 +100ms），丢包率超过 5%~15%。
* **直连线路（Direct BGP）**：
  * 无国内中转入口，客户端直连海外节点；
  * 易受运营商 QOS 流量整形与 DNS 污染影响，稳定性随地区和时段波动极大。

## 🤖 AI 工具与流媒体解锁测试方案

海外高端平台对机房 IP 实施严格的风控阻断。我们的验证规范如下：

### 1. OpenAI / ChatGPT 解锁检测
* 访问 `chatgpt.com` 与 `api.openai.com`；
* 验证是否出现 Cloudflare Turnstile 循环人机验证或 `Access Denied` (1020/403)；
* 验证是否被降级至 `GPT-4o mini` 限制模式或阻断登录；
* 判定标准：纯净住宅双 ISP IP > 原生机房双 ISP IP > 广播机房 IP。

### 2. 流媒体全解锁检测
* **Netflix**：必须能播放地区限定非自制版权剧（例如日区、韩区独立版权番剧），而非仅能播放 Netflix Originals 自制剧；
* **Disney+**：必须能正常加载首页海报流并无报错开启 4K HDR 杜比视界码流；
* **YouTube Premium**：定位地区与免翻广政策需精准匹配。

## ⚖️ 综合评级加权算法

每篇评测的总评分依据以下加权公式严格计算：

$$\text{Final Score} = S_{\text{稳定}} \times 0.35 + S_{\text{速度}} \times 0.25 + S_{\text{解锁}} \times 0.20 + S_{\text{性价比}} \times 0.15 + S_{\text{易用}} \times 0.05$$

* **网络稳定性 ($35\%$)**：晚高峰丢包表现、多运营商（电信/联通/移动）互通性、SLA 探活历史。
* **速度与带宽 ($25\%$)**：高峰期突发带宽、大文件拉取速率、YouTube 4K 秒开缓冲。
* **解锁与纯净度 ($20\%$)**：住宅双 ISP 占比、流媒体跨区完整度、AI 工具风控豁免率。
* **性价比与售后 ($15\%$)**：月付门槛、工单响应时效、Telegram 运维交流群透明度。
* **客户端支持 ($5\%$)**：一键订阅转换、主流核心适配文档完整度。

## 📌 数据有效期与版本声明

* **评测周期**：每季度对排行榜核心品牌进行数据复测；
* **重大变动触发**：若遇国际海底光缆中断、大规模出口波动或品牌主控更换，实验室将在 7 个工作日内启动加急重测并在对应评测页面标注更新；
* **历史归档**：历史版本测速记录移入归档库，保障长期可信度与读者知情权。
