## 🛠️ 五大排查步骤详细操作指南

### 第一步：校准本地设备系统时间（最关键、最高频诱因！）
* **故障机理**：现代代理协议（Shadowsocks、VLESS、Trojan、TLS 1.3）在握手通信时包含严格的 **时间戳校验机制**。如果你的电脑或手机本地时间与国际标准北京时间相差超过 **90 秒**，服务器会判定为重放攻击而直接丢弃握手包，导致测速 100% 出现 `Timeout`！
* **Windows 修复方法**：
  1. 鼠标右键点击屏幕右下角的时间日期 ➔ 选择 **`调整日期和时间`**；
  2. 确保开启 **`自动设置时间`** 开关；
  3. 点击下方 **`立即同步`** 按钮，确保显示“上次成功同步时间”为刚刚；
  4. 回到客户端重新测速，所有节点瞬间恢复绿灯！
* **macOS 修复方法**：打开 `系统设置 > 通用 > 日期与时间`，开启“自动设置日期和时间”。

---

### 第二步：登录机场后台核验套餐与流量状态
* 许多用户因未注意流量额度，月初流量超标或套餐到达周期自动停机。
* 登录你的机场后台面板，查看：
  1. **剩余流量** 是否显示为 `0 MB`；
  2. **到期时间** 是否已过期；
  3. **账户余额 / 服务状态** 是否处于“正常”。

---

### 第三步：检查客户端代理模式与策略组
* 在 [Clash Verge Rev](/client/clash-verge) 中，确认顶部模式处于 **`规则 (Rule)`**；
* 展开 `PROXY` 或 `节点选择` 策略组，确认你确实**左键点击选中了一个具体可用的节点**（有时策略组处于未选中或默认空值状态）；
* 切勿选择 `DIRECT`（直连）模式，否则测速或访问外网均不走代理。

---

### 第四步：检查杀毒软件与 Windows 防火墙拦截
* 某些杀毒软件（如 360 安全卫士、火绒特定拦截规则）可能会静默拦截 Clash 内核的本地 Socks5 监听端口（默认 7890 端口）。
* 尝试临时退出第三方杀毒软件，或在防火墙允许应用列表中勾选 `clash-verge.exe` 及 `mihomo.exe`。

---

### 第五步：开启 TUN 模式或刷新订阅
* 若依然无法连接，可能是本地网络端口被其他程序占用。
* 在 Clash Verge 中开启 **`TUN 模式`**，让虚拟网卡强制接管流量；
* 点击 `订阅` ➔ 右键 `更新订阅`，获取服务商最新更新的节点 IP。

## ❓ 节点超时与全红高频 FAQ (10条必备解答)

::: details 1. 为什么有的节点超时，有的节点延迟正常？
这通常是因为机场的部分节点正在进行机房维护或线路切换。只要列表中还有其他绿色低延迟节点可用，只需手动切换到正常的节点即可，无需担忧。
:::

::: details 2. 节点测速全部显示 9999ms 代表什么？
9999ms 是客户端对于“连接超时未响应 (Timeout)”的数值化展示，通常等同于无法连通，请按照本文的 5 步排查法依次解决。
:::

::: details 3. 为什么手机小火箭测速全绿，电脑 Clash 却全红？
这恰恰证明了**不是机场服务器问题，而是电脑本地环境问题**。请重点检查电脑本地时间是否同步，以及电脑是否开启了其他代理软件导致本地 7890 端口冲突。
:::

::: details 4. 什么是 URL-Test？为什么有时候自动测速不灵敏？
URL-Test 是客户端内置的自动测速机制，默认每隔几分钟向 Google 发送一次 Ping 请求。如果 Google 测速地址被临时拦截，可能会导致客户端误判。可在设置中将测速 URL 修改为 `http://www.gstatic.com/generate_204`。
:::

::: details 5. 使用校园网或公司 Wi-Fi 节点全部超时怎么办？
部分学校或公司内网在网关层面封锁了常见的非标准代理端口或 UDP 流量。**解决方法**：在手机上开启 4G/5G 个人热点，将电脑连接到手机热点再次尝试，如果恢复正常，则说明是局域网网络限制。
:::

::: details 6. 为什么节点全红后重新导入订阅还是不行？
如果本地时间没有校准，或者套餐已过期，重新导入一百次订阅依然会是全红。务必先排除系统时间和账户状态这两个核心诱因。
:::

::: details 7. 遇到敏感时期大面积超时该怎么应对？
公网直连中转节点在敏感期容易受干扰。建议常备一家拥有 [全内网 IEPL 专线](/ranking/stable) 或 [按量计费备用包](/cheap/pay-as-you-go) 的服务商，专线不过公网，在敏感期依然坚挺可用。
:::

::: details 8. 电脑休眠唤醒后经常全部超时怎么解决？
电脑休眠时网络连接断开，唤醒后 Clash 内部的连接池未及时重置。只需在任务栏右键退出 Clash 并重新打开即可一键复原。
:::

::: details 9. 节点延迟 30ms 和 200ms 在日常体验上有很大区别吗？
访问网页和观看视频（如下载缓冲）区别不大，因为带宽大小决定了视频清晰度；但在外服游戏联机、语音通话或 SSH 终端敲命令时，30ms 相比 200ms 会带来质的飞跃。
:::

::: details 10. 如何判断一个机场是不是真的跑路了？
查看机场官网是否还能打开、官方 Telegram 通知频道是否有最新维护公告。如果官网域名解析失效超 72 小时且频道失联，则大概率属于跑路。选择运营 3 年以上的老牌服务商可极大降低此类风险。
:::
