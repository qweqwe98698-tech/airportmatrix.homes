## 📱 二、手机 Wi-Fi 正常但 4G/5G 流量无法使用排查

当手机离开 Wi-Fi 环境切换至蜂窝移动网络时，代理失效的 4 大根因与对策：

| 故障根因 | 典型表现 | 终极解决步骤 |
| :--- | :--- | :--- |
| **运营商 IPv6 路由阻断** | 移动/电信 5G 分配了纯 IPv6 地址，导致客户端 IPv4 映射失败 | 在客户端设置中开启 **【启用 IPv6 支持】** 或在手机 APN 设置中将协议修改为 `IPv4/IPv6 双栈`。 |
| **应用未授予蜂窝流量权限** | 在 Wi-Fi 下能用，断开 Wi-Fi 提示无网络 | iPhone 进入【设置】->【蜂窝网络】-> 找到代理软件，确认为 **【WLAN 与蜂窝数据】** 均允许。 |
| **TUN 虚拟网卡未随网络切换** | 切换网络后延迟显示 0 或全部节点红 | 在代理客户端中点击 **【断开连接】**，等待 3 秒后重新点击 **【启动连接】**，重建虚拟网卡路由。 |
| **省电模式冻结后台 VPN** | 熄屏或切应用后移动流量断连 | 在手机【电池优化】中将客户端设为 **【不优化 / 允许无限制后台运行】**。 |

## ❓ 代理断网与流量冲突常见 10 大疑问与解答 (FAQ)

::: details 1. 为什么电脑连微信能聊天，但打开网页就提示“代理服务器拒绝连接”？
因为微信走的是独立的 TCP 长连接端口，不依赖浏览器的系统代理；而浏览器所有 HTTP/HTTPS 请求都会严格走系统代理。当代理软件关闭而系统设置里的代理端口未移除时，浏览器就会报错。
:::

::: details 2. 使用手机热点共享给电脑，电脑连上代理为什么很慢？
手机开启个人热点时，通常对并发 UDP 报文有限制。在电脑端客户端设置中**关闭 QUIC 协议**，强制走 TCP 专线传输，速度即可大幅回升。
:::

::: details 3. 为什么 iPhone 切换 Wi-Fi 后小火箭 (Shadowrocket) 经常卡住？
这是 iOS 系统在切换不同网关时的网络握手延迟。在小火箭主界面轻按断开再重新开启，让系统重新建立 WireGuard / TUN 虚拟通道。
:::

::: details 4. 重置 Winsock 目录命令是什么？什么时候需要用？
当电脑因杀毒软件或网络修复工具破坏了代理栈时，以管理员身份运行 CMD，输入：
`netsh winsock reset`
然后重启电脑，即可 100% 修复所有网卡底层协议冲突。
:::

::: details 5. 为什么在公司 Wi-Fi 下无法连接任何机场节点？
很多企业内网路由器部署了行为管理防火墙（如深信服、深信度阻断），拦截了出网的非标端口（如 10000+ 端口）。建议在客户端中选择 **443 端口的标准 TLS 节点 (VLESS / Trojan)** 伪装流量。
:::

::: details 6. 安卓手机的“专用 DNS (Private DNS)”会影响代理吗？
会。部分第三方私有 DNS（如某些去广告 DNS）会破坏客户端的 Fake-IP 域名劫持。建议在手机设置中将【专用 DNS】设为 **【关闭】** 或 **【自动】**。
:::

::: details 7. 开启 TUN 虚拟网卡模式后，局域网打印机搜不到怎么办？
在客户端的 TUN 配置中开启 **【严格路由 (Strict Route)】** 并确保将私有私网网段 `192.168.0.0/16` 排除在代理路由表之外。
:::

::: details 8. 为什么换了一张手机 SIM 卡后代理订阅全部不能用了？
更换 SIM 卡后本地移动网络的接入点 (APN) 发生了重置，且系统会清除应用的网络权限。请重新检查客户端的蜂窝网络数据权限。
:::

::: details 9. 电脑 Hosts 文件被篡改会导致打不开网页吗？怎么修复？
会。打开 `C:\Windows\System32\drivers\etc\hosts` 文件，清空里面所有关于 Google、GitHub 的陈旧自定义 IP 解析记录，恢复为默认空状态。
:::

::: details 10. 经常遇到节点突然断流，换什么线路能彻底解决？
公网直连中转节点极易受国际光缆拥塞影响。彻底摆脱断流建议升级为采用内网物理直连的 **IEPL 纯专线机场**（如 [光速云 5 年老牌专线](/ranking/guangsu) 或 [速界](/ranking/stable)）。
:::
