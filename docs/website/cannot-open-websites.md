## 🔬 为什么国外网站打不开？（底层原理大白话）

```
[国内电脑请求] ──(包含海外域名)──> [国内运营商 DNS] ──(遭遇 DNS 污染 / 阻断)──> ❌ 返回错误 IP / 超时
                                    │
                                    └──> [通过代理客户端加密封装] ──> [专线节点] ──> [海外网站 (秒开)]
```

1. **DNS 污染 (DNS Poisoning)**：当你在浏览器输入 `google.com` 时，本地网络向运营商 DNS 查询服务器 IP，系统返回了一个不存在的虚假 IP 地址，导致网页死活打不开。
2. **IP 黑洞与 TCP 阻断**：目标海外服务器的 IP 地址在国际出口路由器处被丢弃数据包。
3. **SNI 握手阻断**：在发起 HTTPS 加密连接时，握手阶段明文暴露的域名被中间设备识别并切断连接。

## ❓ 国外网站访问高频 FAQ (10条必备解答)

::: details 1. 为什么微信/QQ能正常聊天，只有国外网站打不开？
因为微信、QQ 等国内 App 的服务器机房部署在中国境内，走的是国内局域网直连；而 Google、GitHub、YouTube 的服务器在海外，需要经过国际出口通道。
:::

::: details 2. 手机怎么浏览国外网站？
苹果 iPhone 用户使用海外 Apple ID 在 App Store 下载 Shadowrocket (小火箭)；安卓用户下载安装 Clash Meta，导入订阅后开启连接即可。
:::

::: details 3. 电脑浏览国外网站一直显示“ERR_CONNECTION_TIMED_OUT”怎么办？
这代表连接超时。请检查：① 代理客户端是否已经启动；② 代理软件内的系统代理开关是否已打开；③ 节点是否已全红（若全红请参考 [节点超时排查指南](/faq/timeout-troubleshoot)）。
:::

::: details 4. 浏览国外网站安全吗？
只要选择正规加密协议（如 TLS 1.3、Shadowsocks 2022、VLESS Reality），所有在网络上传输的数据均经过军工级高强度加密，第三方无法窃听你的浏览内容。但请勿在不可信的公共免费节点上输入银行账号。
:::

::: details 5. 为什么有的国外网站能打开（如微软 Bing），有的打不开？
微软在国内部署有专门的 CDN 边缘加速节点与合规机房；而大部分海外网站未在国内设立机房，直接受国际网络阻断影响。
:::

::: details 6. 如何清理本地受污染的 DNS 缓存？
在 Windows 中按下快捷键 `Win + R` ➔ 输入 `cmd` 回车 ➔ 在黑框中输入 `ipconfig /flushdns` 回车，即可彻底清空本地所有旧 DNS 缓存。
:::

::: details 7. 遇到国外网站提示“403 Forbidden”或拒绝访问怎么办？
这通常是因为目标海外网站屏蔽了机房代理 IP（例如部分银行、政企系统）。尝试在客户端中切换至住宅原生 IP 节点或开启 TUN 模式。
:::

::: details 8. 访问国外网站会消耗很多手机流量吗？
纯文字和图片网页消耗流量极少（一篇网页约 1~3MB）；观看 1080P 高清视频每小时约消耗 1.5GB 流量。只要不挂机长时间下载大文件，常规套餐流量完全足够。
:::

::: details 9. 为什么挂了代理后有些国内网站反而打不开了？
因为客户端可能误选了“全局模式 (Global)”。请在客户端中将代理模式切换为 **“规则模式 (Rule)”**，此时客户端会自动实现“国内网站走直连、国外网站走代理”，两全其美互不影响。
:::

::: details 10. 高校学生与科研人员如何合法查阅外文文献？
许多高校图书馆购买了 Web of Science、IEEE 等数据库的 CARSI 统一身份认证权限；若在校外访问外文期刊或 Google Scholar，搭配个人合规科研加速专线即可无障碍检索。
:::
