# 🌿 关于 AirportMatrix 评测实验室

欢迎访问 **全球机场 · 森林知识屋 (AirportMatrix)**。我们是一个由网络工程师、分布式系统开发者与海外学术研究者自发组建的独立网络连通性评测与协议研究实验室。

---

## 🎯 我们的使命与初衷

在跨境网络访问与学术科研领域，用户长期面临信息不对称与虚假宣传的困扰：
* **劣质中继充当内网专线**：大量服务商以廉价公网中转冒充高成本 IPLC/IEPL 专线，在晚高峰骨干网拥塞时丢包率骤增至 30% 以上。
* **流媒体与 AI 解锁虚标**：声称原生住宅双 ISP IP，实际为高风险数据中心机房 IP，导致 ChatGPT 频繁遭遇 `Access Denied` 或风控降智。
* **商业水军与无底线吹捧**：评测内容高度同质化，掩盖晚高峰限速、月付跑路、退款无门等关键风险。

**AirportMatrix 实验室的创立目标**：构建一套透明、量化、基于真实全天候多运营商实测的评测标准，以网络工程视角拆解底层链路技术，帮助科研人员、出海工程师、跨境电商从业者与海外留学生挑选安全、稳定、高性价比的网络工具。

## 🔬 评测团队与技术架构分工

我们的编辑与技术研究协作围绕三大实证方向展开：

* **网络拓扑与路由研究组**：专注于 BGP 选路分析、晚高峰抖动评估及 IPLC/IEPL 物理内网专线时延特征研究。
* **协议指纹与风控检测组**：专注于 TLS 1.3 指纹、VLESS/SS2022/Hysteria2 传输特征及海外应用（ChatGPT/Claude/Netflix）IP 纯净度验证。
* **数据采集与归档规范组**：结合主流开源/社区测速探针工具（如 `MAI-TEST-BOT`、`MiaoKo`、`MiaoSu` 等带时间戳与节点批次信息的实测快照）及定期复核机制，建立可追溯的公开对比档案。

## 🛡️ 编辑独立性与透明分级准则

为避免“用未核实资料充当实测结果”，本站严格执行以下四条公开规范：

1. **四级数据来源显式隔离**：本站将收录的 42 家服务商明确区分为「有实测/解锁原图（含时间戳与工具版本）」「厂商参考参数与非晚高峰测速」「品牌公开资料」及「历史归档/待核实」，绝不将未经测速确认的条目伪装为实测数据。
2. **拒绝付费篡改评测结论**：我们不接受任何厂商通过付费、充值或赞助要求修改评测局限说明或虚构实测快照成绩的行为。
3. **数据优先与原始参数留存**：每份带有测速截图的评测页面均保留原始测试时间、测试工具版本、电信/联通/移动后端标注及局限提示，方便读者自行核对。
4. **定期复测与降级机制**：网络服务质量具有时效性。对于缺少近期连续实测数据、优惠码状态存疑或官网入口变更的服务商，本站将其自动标为「待核实」并移入后排档案区。

## 🏗️ 评测基础设施

为了杜绝单点测试的片面性，我们在中国大陆主要骨干网络枢纽节点部署了自建测试探针：
* **电信骨干节点**：上海电信 CN2/163 出口、广州电信骨干出口；
* **联通骨干节点**：北京联通、山东联通 AS4837/AS9929 出口；
* **移动骨干节点**：广东移动、江苏移动 CMI 出口；
* **测试时间窗口**：覆盖平日低峰期（10:00 - 16:00）、晚高峰拥塞期（20:00 - 23:30）以及节假日负载波动期。

详细测试方法与量化指标请查阅 [评测方法论与质检标准](/methodology)。
