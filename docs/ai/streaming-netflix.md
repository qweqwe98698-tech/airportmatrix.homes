## ❓ 流媒体追剧常见问题解答 (FAQ)

::: details 1. 为什么看 Netflix 或 Disney+ 必须选大流量套餐？
YouTube 1080P 每小时消耗约 1.5~2GB，而 Netflix / YouTube **4K HDR 视频每小时会消耗 6~8GB 流量**。经常看 4K 剧集的用户建议选择每月 100GB~150GB 以上的套餐（如 [一翻云](/ranking/yifanyun) 或 [2026 性价比机场榜](/ranking/budget) 中的百 G 月付方案）。
:::

::: details 2. 为什么有些香港节点打不开 Disney+ 或只能看 Netflix 自制剧？
由于部分香港常规机房 IP 段被版权方封锁，或者节点未配置跨区解锁策略。若遇到提示错误，可切换至机场节点列表中标注 `解锁` / `流媒体` 或日本、新加坡、台湾原生节点，并避免频繁跨区切换账号 IP。
:::

::: details 3. YouTube 晚高峰看 4K 一直转圈卡顿怎么排查？
打开视频右键【详细统计信息 (Stats for nerds)】，查看 `Connection Speed`。若低于 30,000 Kbps，说明当前节点公网拥堵或本地开启了全局模式冲突，可切换 IEPL 专线节点或参考 [YouTube 卡顿一直转圈修复指南](/website/youtube-buffer-fix)。
:::
