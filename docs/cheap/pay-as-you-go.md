## ❓ 按量计费常见问答 (FAQ)

::: details 1. 不限时流量包真的不会在月底自动清零吗？
是的。不限时按量计费的核心规则就是“不设固定到期日，余额用完为止”。购买时请在套餐详情页确认明确标注“不限时 / 永久有效”，不要误买成常规月付/年付周期套餐。
:::

::: details 2. 按量计费机场和 7 元年付机场（如飞猫云、光速云）怎么选？
如果你**每月稳定消耗 20GB~50GB**，按年折算约 7~7.5 元/月的 [光速云](/ranking/guangsu) 或 [飞猫云](/ranking/feimao) 单 GB 成本更低；如果你**一个月用不到 5GB**，或者只需要一条备用线路，选 [星岛梦](/ranking/xingdao) 不限时按量套餐更省钱。
:::

::: details 3. 使用按量套餐需要注意节点倍率吗？
需要注意。部分机场的冷门或高带宽专线节点会设置 2x、3x 倍率（即下载 1GB 扣除 2~3GB 流量）。星岛梦主流节点标注为 1.0x 标准倍率，扣量更透明。
:::

::: details 4. 按量流量包买完如果长时间不用，会因为机场维护或改域名而失效吗？
任何机场都有域名变更的可能，因此建议优先选择开业满 3 年以上、拥有独立发布页或客户端的稳定老牌（如运营 5 年的 [星岛梦](/ranking/xingdao)），并定期保存好官网防失联发布地址，避免只收藏单一临时登录域名。
:::
